# 🧠 心理课设计方法论

中小学心理健康教育课程的系统化设计框架。

## ✨ 特色

- **7种理论模型库**：情绪ABC、情绪粒度、"我信息"、积极心理学PERMA、CBT认知三角、意义治疗、坚毅力
- **6步设计法**：主题选择→理论基础→学情分析→目标制定→活动环节设计→课程评价
- **6个完整课例**：覆盖小学到高中，含情绪管理、人际关系、自我认知、学习心理、生命教育
- **6套评价工具**：课堂观察表、自评表、互评表、出口票、学情调研问卷、行为表现评价表
- **发展心理学参考**：埃里克森阶段理论 + 皮亚杰认知发展（含年龄对照表）
- **理论选择速查表**：按主题方向快速匹配推荐理论
